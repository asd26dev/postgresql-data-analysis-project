# PostgreSQL Data Analysis Project

## 📌 Project Overview
This project contains end-to-end data analysis workflows using PostgreSQL. It demonstrates querying techniques to extract actionable insights, solve business problems, and perform analytical aggregations.

---

## 🗂️ Project Structure
* `Project_PostgresSQL.sql` - Complete SQL scripts containing table schemas, data transformations, and analysis queries.

---

## 🛠️ Concepts & Techniques Covered
* **Data Definition & Manipulation:** Table creation, data cleaning, filtering, and constraints.
* **Aggregations & Grouping:** `GROUP BY`, `HAVING`, summary statistics.
* **Joins & Relationships:** `INNER JOIN`, `LEFT JOIN`, multi-table queries.
* **Advanced SQL:**
  * Subqueries & Common Table Expressions (CTEs)
  * Window Functions (`ROW_NUMBER()`, `RANK()`, `LAG()`, `LEAD()`, moving averages)
  * Conditional logic using `CASE WHEN`

---

## 📊 Key Business Questions Solved
1. **Sales & Revenue Performance:** Top products, monthly revenue growth, and seasonal trends.
2. **Customer Segmentation:** Identifying high-value customers and repeat purchase behavior.
3. **Operational Metrics:** Order fulfillment metrics and performance tracking.
